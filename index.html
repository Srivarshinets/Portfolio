Things I’ve built

The one with a patent application, Healing Hands

A yoga mudra detection and correction system that runs entirely in the browser, classifying hand poses from a live webcam feed with 90% accuracy. Built as a team; I developed the frontend and collected the training dataset.

IEEE paper · Recognized by KSCST and Art Park–IISc · Patent application filed

  • TensorFlow.js
  • OpenCV
  • NumPy
  • JavaScript

Try the site yourself

The fast one, F1 Telemetry Dashboard

A comparative analysis tool for race telemetry. It pulls real-time and historical data from the FastF1 API, cleans it with Pandas, stores it in MySQL, and compares speed, throttle, brake, gear and distance across drivers. I scoped and delivered it end to end.

  • Python
  • Pandas
  • MySQL
  • Matplotlib

See the code on GitHub

The sharp-eyed one, Image Classification

A supervised image classifier with preprocessing and data augmentation, tuned over several rounds of evaluation until it hit 90% accuracy on held-out test data.

  • TensorFlow
  • Keras
  • Python

The one with a pulse, Cardiac Monitor

A heart rate monitor on an Arduino Uno. It reads the analog pulse sensor signal, calculates BPM in embedded C, and shows the live reading on an LCD.

  • Arduino
  • Embedded C
